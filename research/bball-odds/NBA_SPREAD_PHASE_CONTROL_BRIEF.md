# NBA spread by phase — the control

The phase split found the model monotone-positive EARLY and inverted across all eight families LATE. Each window has a one-line rule that already works in it (home early, favourite late), so the only question that matters is whether the model adds anything on top of that rule.

`delta cell` is the deciding column: the naive rule reweighted to the selection's own |open spread| bucket mix. `naive share` is how often the model's pick simply IS the naive side — a fade that is 95% favourites is the favourite rule wearing a hat, whatever its delta says.
