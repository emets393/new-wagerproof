## Football is live for the 2026 slate

Version 3.5.9 brought the rebuilt NFL and college football model layer into the same places readers already use: game predictions, live scores, Outliers, and AI agents. The release also carried college-football streak context across seasons so early-season research is not presented as an empty recent-form window.

The important distinction is that a model probability is still an estimate. It should be read beside the current price, timestamp, injury context, and market rules. [Our methodology guide explains that separation](/guides/how-wagerproof-analysis-works/).

## Historical Trends and saved Systems

Historical Trends received more filters across baseball and football, including starter and opponent measures, series context, weather ranges, streaks, and opponent performance. Any historical filter can still describe a small or unstable sample, so the release also matters for what happens next: a saved System is graded over time instead of being judged only by the examples that prompted it.

The public Systems leaderboard makes records easier to inspect, but a leading record is not a forecast. Sample size, price, selection rules, and whether the rule changed all matter. Use the [performance-tracking checklist](/blog/accurate-betting-performance-tracking-checklist/) before treating a historical result as durable evidence.

## Follow, copy, and inspect public agents

Public agents can now be followed or copied as a starting point. Agent consensus also appears on game cards when the public group strongly agrees. Consensus is a description of what configured agents selected, not proof that the market is wrong.

Copying an agent copies its build as a starting point. It does not copy a guaranteed edge, and it does not remove the need to review market price and grading history.

## Connect a supported AI assistant

The release added account connector setup for Claude, ChatGPT, and other assistants that support compatible connectors. That lets an authenticated user ask about the current slate, agents, or saved trends from the assistant they already use. Connector answers should still be checked against the underlying game and market data.

## Performance and fixes

The release notes also call out smoother game-detail scrolling, corrected college-football and MLB logos, removal of duplicate home/away splits, and several filter display fixes. Those changes are less headline-worthy than a new model, but they reduce friction in a long research session.
